# Contributing

Thanks for looking. claim-seal is kept by one person, and I don't read code myself (see the AI;DR note at the top of the README).

- **A bug or a wrong result:** open an issue. Include the writing, the sources (or links to them), what claim-seal said, and what you expected. I read issues with an AI assistant's help, so replies can be slow.
- **Pull requests:** I don't merge them. I can't review code myself, and I'd rather not take changes I can't check. If you have a fix, describe it in an issue; it may be rebuilt and tested here.
- **A security problem:** please don't open a public issue. Use private vulnerability reporting, as described in [SECURITY.md](SECURITY.md).
